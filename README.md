# KICKS - Premium Sneaker Store

A modern, responsive e-commerce frontend for a fashion shoe store built with React and Vite.

## Features

- **Modern UI/UX**: Clean, minimalist design with smooth animations and transitions.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop devices.
- **Product Browsing**: Filterable shop page to explore the collection.
- **Product Details**: Detailed view for each product with image galleries and size selection.
- **Routing**: Seamless client-side navigation using React Router.

## Tech Stack

- **React**: UI Library
- **Vite**: Build Tool
- **React Router**: Navigation
- **Lucide React**: Icons
- **CSS**: Custom styling with CSS Variables

## Getting Started

1.  **Install dependencies:**

    ```bash
    npm install
    ```

2.  **Run the development server:**

    ```bash
    npm run dev
    ```

3.  **Open in browser:**
    Navigate to `http://localhost:5173` (or the URL shown in your terminal).

## Project Structure

- `src/components`: Reusable UI components (Navbar, Hero, ProductCard, Footer)
- `src/pages`: Page components (Home, Shop, ProductDetails)
- `src/data`: Mock data for products
- `src/index.css`: Global styles and theme variables

## Customization

You can easily customize the theme by editing the CSS variables in `src/index.css`.
